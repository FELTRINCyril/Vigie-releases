Confidentialité

Vigie fonctionne entièrement sur votre Mac : pas de compte, pas de serveur, pas de pisteur. Il se connecte seulement à GitHub pour vérifier les mises à jour.

Vigie est une app indépendante, gratuite, sans lien avec Apple.
